# Pinkbin

AI 对话式空间分析 + 传统规则清理，Windows 便携版。

[下载便携版](https://github.com/OmoriRay/Pinkbin/releases/latest) · [使用说明](docs/使用说明.md) · [更新记录](docs/CHANGELOG.md) · [English](README_EN.md)

</div>

## 这个版本做了什么

基于 [cccyd2003-qwq/pinkbin](https://github.com/cccyd2003-qwq/pinkbin) 修改，保留原项目的粉色界面和 AI 对话式空间分析。当前版本 **v0.11.7**，面向 Windows 10 / 11 x64。

- 移除右侧 Studio，保留文件树与 AI 对话作为主界面。
- AI 无须扫描即可对话；扫描后可以结合文件元数据分析，支持兼容接口和本地 Ollama。
- 加入固定本地磁盘的全盘检查、跨重启快速复查，以及经过规则限定的常用缓存检查。
- 全盘检查完成后提供「便捷清理」推荐卡片和固定底栏按钮，在全盘遍历时识别缓存、过期临时文件及旧排障记录，不调用 AI、不混入手动选择。
- 清理结果与历史集中展示；分类全选跨分页，支持复制文件信息和已选文件信息。
- 主页整盘分析与全盘清理共用一次遍历；15 分钟内优先使用已有结果，增加盘符时只补扫缺少的盘。扫描由后台保留，界面刷新后重新连接；退出程序后任务不保留。
- 窗口尺寸在显示前恢复；AI 回复显示耗时，提供连接测试与网络连接复用。
- 程序自己的设置、窗口状态、记录和 WebView 数据放在 exe 同级的 `PinkbinData`。

## 下载和使用

从 [Releases](https://github.com/OmoriRay/Pinkbin/releases/latest) 下载 `Pinkbin_0.11.7_windows_x64.zip`。将 ZIP 完整解压到有写入权限的文件夹，再双击其中的 `Pinkbin.exe` 使用，无须安装包。不要直接在压缩包内运行。Windows 需要 WebView2 Runtime；多数 Windows 10 / 11 设备已经具备。

首次使用会在 exe 旁创建 `PinkbinData`。已有旧版 AppData 设置时会尝试导入，原数据保留。以后移动软件，请将 **exe、rules 与 PinkbinData 一起移动**。数据目录含有本机 AI 配置，请不要上传到仓库或分享给其他人。

使用 AI 时，在设置中填写服务商提供的 Base URL、API Key 和模型名，再点击小型测试按钮。调用第三方服务的费用及可用性由服务商决定。

## 清理范围

全盘检查遍历所选的可访问固定本地盘，列出较旧临时文件、崩溃转储、日志、安装介质和大文件。系统关键目录和软件环境仅统计空间；明确规则允许的旧临时文件、归档报告和维护日志单独检查。链接、权限或扫描限额会影响覆盖范围。

便捷清理将全盘遍历中识别的过期临时文件、旧崩溃转储、pip/npm 下载缓存、可重建的 Python 编译缓存，旧 Windows 错误报告、内核转储、NuGet 下载缓存、Rust 增量缓存，以及已验证应用和独立安装浏览器的缓存，合并为一个推荐计划。相关应用运行时跳过；只处理所选磁盘，不把安装包、模型、账号、聊天或工作资料推荐删除。缓存可能需要重新生成或下载，旧排障记录删除后不保留。

**大文件、旧文件不等于垃圾。** 全盘候选默认不选，需要人工核对后勾选。点击“直接删除”立即执行，不再进入确认页。清理不依赖 AI，直接删除所选文件，不经过回收站，无法从回收站恢复。

普通文件分析发送路径、大小等元数据，不读取文件正文；主动附加的图片会发送给所配置的 AI 服务。对话本身不能直接执行清理。

## 独立清理规则库

常用缓存设置、应用目录、进程保护、保留天数和排除项集中在 [`rules/cleanup-catalog-v7.json`](rules/cleanup-catalog-v7.json)，覆盖应用缓存、已归档诊断和安装暂存。笔记、离线数据库、账号、备份仍保留。软件发现继续使用全盘元数据遍历和目录/程序标记，不需要 AI。

ZIP 带有 `rules` 文件夹，放在 exe 旁。未来在现有模板内扩展规则可以单独更新该文件，重启程序后生效；没有外部文件时使用程序内置规则。外部文件格式或保护条件错误时会停止清理扫描并报错。维护格式、边界和验证命令见 [规则库说明](rules/README.md)。

## v0.11.7：重复启动与归档日志

同一软件目录重复打开时唤起原窗口，最小化后恢复；同目录旧版仍运行时先提示退出，独立便携目录各自运行。启动保护先于配置和 WebView 初始化，不重开现有扫描。

v7 增加 OBS 会话日志/崩溃报告、Stability Matrix 归档日志与 Unreal 崩溃报告器备份日志，至少保留 30 天。要求固定位置、软件标记及明确文件名格式，保留当前日志、OBS 最新一份日志/报告、配置、场景与模型，软件运行时跳过。

## v0.11.6：简化勾选反馈

去掉清理勾选框的偏移投影与聚焦跳动；软件标签使用小型圆角勾选框，鼠标点击后不再常驻整圈描边，键盘焦点继续可见。

## v0.11.5：扩充规则与固定程序名

程序统一为 `Pinkbin.exe`，版本号保留在界面与 ZIP 名称中。升级时退出旧程序，将新包解压到原目录并替换程序和规则，保留 `PinkbinData`；已有指向 `Pinkbin.exe` 的快捷方式继续可用。

增加 Steam 至少 7 天的网页缓存，以及 Cherry Studio、123云盘、OpenCode 至少 30 天的已安装更新器副本。仅匹配各自更新缓存根目录的 `installer.exe`，保留 `pending` 中待安装的更新与元信息；需要对应软件标记，相关软件或安装进程运行时跳过。清除副本后，下次差分更新可能改为完整下载。新规则使用 v6，旧规则保留供旧程序使用。

## v0.11.4：连接成功提示

AI 连接测试成功后，模型输入框下显示薄荷绿提示条，带勾选图标、加粗文字和耗时。

## v0.11.3：选择软件与结果复查

便捷清理可取消不想清理的软件，数量和容量随选择更新；同次扫描刷新后保留选择。清理结果可直接快速复查原磁盘，常用缓存结果可直接重新检查缓存。实际执行和记录仅包含选中项目。

## v0.11.2：补齐快速复查目录

修复快速复查漏掉 GraphiteDawnCache 等已审核缓存，以及软件 Crashpad/reports 旧崩溃记录的问题。标准目录与缓存规则共用模板，完整检查后也能保存这些位置。每次仍重新检查文件、软件占用和删除资格；不把整个用户目录或所有 reports 目录纳入清理。

## v0.11.1：精简界面文案

删除清理页的重复介绍、口号条和扫描调试参数。保留检查范围、永久删除后果、进度和失败原因；AI 等待状态只显示一处，并继续计时。设置页说明消息、文件信息和附图会发送给所配置服务。扫描与清理规则不变。

## v0.11.0：快速复查与规则扩充

「磁盘清理 → 磁盘检查」新增快速复查。完成一次新版全盘检查后，只记住少量已核验的清理目录，重开软件后可直接复查这些位置中的当前文件，不必再次遍历整盘。首次使用也可检查已知的标准目录；新安装、搬移软件或想重新了解整盘占用时，仍使用全盘检查。快速复查只显示规则推荐项，不生成主页空间树或人工大文件列表。

位置记录保存在 `PinkbinData/known-cleanup-locations-v1.json`，最多 512 KiB、2,048 个目录；各盘保留名额，优先记住稳定软件目录，不保存文件清单或历史删除授权。记录过期、损坏或不可验证时退回标准目录，每次复查和删除仍重新核验规则、身份、父链、时间及进程状态。普通全盘共享结果仍只保留在内存中。

新增两类 Hugging Face 规则：至少 45 天的精确 Xet shard 索引缓存，以及至少 30 天、对应完整资产仍存在且元信息吻合的随机下载残片。保留模型、上传暂存、旧式可续传文件与未知格式；不直接删除 uv 缓存。新规则使用 v5，v1–v4 保留供旧程序使用。

清理检查可读取至多 512 字节的软件缓存元信息，不读取模型或个人文件正文，也不向 AI 发送这些缓存元信息。界面仍沿用粉色与薄荷绿风格，主页 AI 分析保持原设计。

## v0.10.1：大目录显示与总览去重修复

文件特别多时，文件树会先按原有优先级选定同层文件与目录，为它们预留展示位置，再展开下层细节，避免大文件被深目录耗尽显示预算挤掉。目录总量、显示预算和清理范围保持原有规则。

同一份共享结果按 C→D→C 切换时，不再重复请求 C 的 AI 总览；显式重新扫描得到新结果后仍正常生成。只记录少量结果标识，不缓存额外文件树、AI 回复或写入磁盘索引。

## v0.10.0：主页与清理共享整盘扫描

从主页或「全盘检查」启动整盘扫描，都会同时准备文件树和规则清理结果。另一个入口会接入正在进行的任务，或复用同次运行中 15 分钟内的结果。先扫 C，再检查 C/D/E，只补扫 D/E；不会把其他盘的删除项目带入仅 C 盘的计划。

普通「扫描」优先使用结果，旁边刷新图标可重新读取磁盘；清理结果页也提供「重新检查」。清理后旧结果失效，文件身份、父目录和占用状态在删除前仍即时检查。复用同一结果不重复请求 AI 总览。只共享内存元数据，不新增持久磁盘索引；退出程序后需重扫。单独文件夹保留原来的快速分析；若共享树中已保留该文件夹，也可直接使用。

首次整盘分析采用能同时准备清理快照的完整遍历，因此不再走只提供空间树的 MFT 快速通道。目录细节按预算和大小裁剪，目录总量继续汇总；不可访问、链接和受保护位置仍遵循原边界。本版没有扩展 v4 规则的删除范围。

## v0.9.0：分类与扫描复用

便捷清理先按“应用缓存、编译与下载缓存、旧日志与故障记录、临时与安装残留”显示文件数及体积，展开后查看软件明细；继续一键处理原推荐计划。

一次扫描内预先整理软件目录，复用产品/源码标记及其父目录的普通文件检查。缓存随扫描结束丢弃，数量、路径和内存预算有界。文件时间、安装暂存生命周期、文件身份、父链和执行前规则检查继续即时核验；删除不使用扫描缓存。本版沿用 v4 规则，已有数据和规则保留。

## v0.8.0：扩展垃圾类型

- 新增已知会话中的旧 Crashpad 转储、Electron 已轮转日志、Cherry Studio/QQ 日期归档日志及旧 npm 运行日志；保留当前日志、数据库日志和报告状态文件。
- 新增 Windows CBS/DISM 已归档维护日志，只开放明确的归档文件名与保留条件，保留当前维护日志及系统修复资料。
- 新增真实临时目录内 Inno Setup/NSIS 的过期安装、解压暂存文件；核验目录创建与修改时间，避免新解压的旧文件误入计划。相关工具运行时跳过。
- 新类型沿用原有便捷清理、进程与身份检查、分批执行和清理记录，不新增确认页面或 AI 调用。旧诊断资料删除后不保留。

## v0.7.0 优化

- 扩大全盘只读统计，系统目录、软件环境和回收站仅计入空间占用，保留原有删除边界。结果页可展开「空间都用在哪里了？」查看主要目录和待核实的缓存位置。
- 新增 QQ、WeGame、MusicFree 和 Wallpaper Engine 界面缓存识别，以及有对应已解压源码的 30 天旧 Cargo 下载包。保护聊天、账号、音乐下载、壁纸项目、备份和修复旧目录。
- 便捷清理按具体软件名汇总并按体积排列，身份检查先排除无效文件，再核验完整父链；只读目录使用独立的轻量元数据路径。
- 分批执行共用一次计划、日志与历史，保留 200,000 项/256 MiB 推荐预算和 15 分钟执行预算；人工选择保持 10,000 项限制。

v4 规则使用独立文件名，已有规则和 PinkbinData 保留。开发验证只删除自有临时夹具，实机核查只读，不自动清理本机资料。

## 从源码运行

依赖：Windows Rust MSVC 工具链、Node.js 20 或更新版本、pnpm 9，以及 Tauri 所需的 Windows 构建环境。

```powershell
pnpm install --frozen-lockfile
pnpm tauri dev
```

构建便携 exe：

```powershell
pnpm tauri build --no-bundle
```

产物位于 `target/release/pinkbin.exe`。执行 `./scripts/package-portable.ps1` 生成用于发布的 ZIP；GitHub Releases 只发布 ZIP。测试使用 `cargo test --workspace`，前端构建检查使用 `pnpm build`。
