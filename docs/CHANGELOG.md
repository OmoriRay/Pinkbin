# 更新记录

## v0.4.1 — 2026-10-26

- 移除界面、版本元数据与说明中的额外版本称呼，统一显示 Pinkbin 与版本号。
- GitHub 发布附件统一为 ZIP，包含程序、使用说明和 MIT 许可证，不打包个人数据。
- 增加统一打包脚本，并让发布工作流使用同一脚本。

## v0.4.0 — 2026-10-26

- 设置、清理记录、窗口状态和 WebView 数据统一保存在 exe 同级 PinkbinData。
- 首次导入旧 AppData 配置时采用独占启动锁、暂存复制和完整成功后发布，保留旧源。
- 窗口显示前恢复保存的尺寸，支持程序所在目录移动后继续使用设置。
- 遇到复制失败、占用、不可写目录或未知非空数据目录时明确停止，避免覆盖配置。

本次发布前的本机验证：Rust 95 项通过、0 失败、1 忽略；13 项原生与文件系统检查通过，覆盖迁移、目录移动、窗口尺寸及实际部署。测试记录不代表所有设备上的行为保证。

## 此前本分支的主要变更

- 移除 Studio，保留 AI 对话式空间分析作为主页。
- 扩展常用缓存规则，增加固定本地盘全盘检查和人工选择的文件分类。
- 清理结果与历史合并展示；增加跨分页全选、复制已选文件信息。
- 后台扫描在界面刷新后重新连接；支持未扫描时直接与 AI 对话。
- 增加回复耗时、中文连接错误、默认/直连切换、小型连接测试和 HTTP 客户端复用。
- 小幅调整通用提示词，不按模型品牌维护变体。
