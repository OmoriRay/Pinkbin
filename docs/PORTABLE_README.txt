Pinkbin

Windows 10 / 11 x64 便携程序。

1. 请先把 ZIP 完整解压到一个有写入权限的文件夹。
2. 双击其中的 Pinkbin 程序使用，无须安装包，不要直接在压缩包内运行。
3. 首次运行会在程序旁创建 PinkbinData，保存设置、窗口状态和记录。
4. 移动软件时，把程序和 PinkbinData 一起移动；升级时请退出旧程序，保留原有 PinkbinData。
5. Windows 需要 WebView2 Runtime。多数 Windows 10 / 11 设备已具备。

AI 功能需要自行填写服务地址、密钥与模型。数据目录包含个人配置，请勿分享。
大文件或旧文件不等于垃圾，清理前请核对用途。移入回收站不等于已释放空间。
